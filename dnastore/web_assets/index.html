UNDER THE HOOD
A transparent path back to your file.
01 / Encode
Streaming maps each byte to four DNA bases. Oligo mode adds indices, a file header, checksums, and redundancy.
02 / Recover
Reverse the mapping or decode an oligo pool. Add controlled read errors to explore the limits of recovery.
03 / Verify
Streaming checks SHA-256; oligo decoding checks CRC-32. Round trips additionally compare original and recovered SHA-256.
