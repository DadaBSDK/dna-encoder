UNDER THE HOOD

Why one changed base breaks the file.

01 / Encode
'H' = 0x4801 00 10 00CAGA

Every byte becomes four bases. The archive also stores the file's length and its SHA-256 fingerprint.

02 / Verify
CATA01 00 11 00'L' ≠ 'H'

Decoding recomputes the fingerprint. Any changed base changes it completely, so the file is refused rather than returned silently damaged.

03 / Correct
CRC-32 + Reed–Solomonstrands rebuilt

This mode has no redundancy, so it detects errors but can't fix them. The full dnastore project adds oligo mode, with per-strand CRC-32 and Reed–Solomon parity that rebuild damaged strands. It runs locally in Python.

helix.Archives are interchangeable with dnastore stream-encode / stream-decode. Research software, not a validated synthesis workflow.
