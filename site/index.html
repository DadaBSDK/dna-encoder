UNDER THE HOOD

Why one changed base breaks the file.

01 / Encode

A direct mapping: every byte becomes four bases. The archive also stores the file's length and its SHA-256 fingerprint.

02 / Verify

Decoding recomputes the fingerprint. Any changed base changes it completely, so the file is refused rather than returned silently damaged.

03 / Correct

This mode detects errors but cannot fix them: there is no redundancy. The full dnastore project adds oligo mode, with per-strand CRC-32 and Reed–Solomon parity that rebuild damaged strands. It runs locally in Python.
