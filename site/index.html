UNDER THE HOOD

How a file survives broken DNA.

01 / Strands
32 bytesindex · data · CRC160nt

The file is cut into short strands, like real synthesized oligos. Each one carries its position and a CRC-32 checksum, so damage stays inside one strand and is always detected.

02 / Repair
CATAtry single editsCRC ✓

A damaged read is fixed by trying every single substitution, insertion and deletion until the checksum matches. Several reads of the same strand are merged by majority vote.

03 / Rebuild or compromise
k data + p parityany p lost → rebuilt

Reed–Solomon parity strands rebuild any lost strands up to the parity budget. Beyond it you still get the file: unrecoverable bytes are flagged and everything else is exact. The research codec in dnastore goes further: sequence constraints, primers and a calibrated nanopore channel.

helix.Archives are interchangeable with dnastore stream-encode / stream-decode. Research software, not a validated synthesis workflow.
